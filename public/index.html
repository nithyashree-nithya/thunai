Where the round-ups go

Go live in four steps

  1. Create a PayPal developer app and test in the sandbox.
  2. Keep the client secret on your server. The machine and this page never hold it.
  3. Create an order for each sale, show the code, and capture it when the customer approves.
  4. Record the round-up portion, then pay partners monthly in a batch.

Which currencies, countries and payout features are available depends on your PayPal account type. Check PayPal's developer documentation first.

Create an order (sandbox)

POST https://api-m.sandbox.paypal.com/v2/checkout/orders
Authorization: Bearer <access_token from your server>
Content-Type: application/json

{
  "intent": "CAPTURE",

  }]
}
